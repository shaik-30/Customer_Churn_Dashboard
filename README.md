# 📊 Customer Churn Analytics Dashboard

## 📌 Project Description
The Customer Churn Analytics Dashboard is a Machine Learning-based web application developed using Streamlit. It helps businesses analyze customer behavior, identify customers who are likely to churn, and visualize important insights through interactive charts and dashboards.

---

## 🚀 Key Features

- 📈 Interactive Customer Churn Dashboard
- 🤖 Machine Learning-based Churn Prediction
- 🎛 Dynamic Sidebar Filters
- 📊 KPI Cards (Customers, Churn, Retained, Churn Rate)
- 🥧 Customer Churn Distribution (Pie Chart)
- 📉 Churn Count Analysis (Bar Chart)
- 📈 Customer Tenure Distribution
- 💰 Monthly Charges vs Churn Analysis
- 📑 Contract Type Analysis
- 🌐 Internet Service Distribution
- 📋 Dataset Preview & Statistics
- 📥 Download Dataset Feature
- ⚡ Fast and Responsive Streamlit Interface

---
